# HireTest AI frontend

The frontend is an installable Progressive Web App (PWA). On Android or desktop, use the browser's **Install app** action. On iPhone or iPad, open the site in Safari, tap **Share**, then **Add to Home Screen**. The app shell is available offline after the first visit; API requests still require a network connection.

## Development

Run `npm install` and `npm run dev`. Run `npm run build` to generate the production bundle and PWA service worker.
